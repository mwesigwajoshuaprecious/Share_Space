Project Application Overview: ShareSpace Hostel Borrowing Club
Project title: ShareSpace Hostel Borrowing Club

INTRODUCTION
ShareSpace is a simple application designed to help university students borrow useful items from one another. A student may need something such as a calculator, textbook, cooking utensil, or extension cable for a short time. Another student may own that item but not be using it.

The application lets students list items they are willing to lend, browse items listed by other students, and send borrowing requests to the item owners. Owners can approve or reject requests, and borrowers can record when they return an item.

PROBLEM STATEMENT
Students sometimes need items that they do not own, while other students nearby may have those items unused. Without a simple way to find and request them, students may spend money buying items they need only temporarily or have difficulty finding someone willing to lend them one.

AIM
To develop a simple object-oriented application that helps university students share and borrow items within and across hostels.

OBJECTIVES
- Allow students to register and provide their hostel information.
- Allow students to list items they are willing to lend.
- Let students browse and search available items.
- Allow a student to request an item from its owner.
- Let the owner approve or reject a borrowing request.
- Track borrowed items and record their return.
- Demonstrate key object-oriented programming concepts.
Main users
- Student: Registers, lists items, browses items, requests to borrow, reviews requests for their own items, and records returns.
- Administrator: Represents a separate user type in the program and demonstrates how different user roles can have different behavior.

MAIN FEATURES
1. Student registration: Creates a student profile with a name and hostel.
2. Item listing: Lets a student add an item they are not currently using.
3. Item browsing: Displays available items, including items from other hostels.
4. Borrowing requests: Allows a student to request another student’s item.
5. Request decisions: Lets the item owner approve or reject a request.
6. Return tracking: Records when an approved item is returned and makes it available again.
